\## Versioning Philosophy



REACLYST will use semantic versioning where appropriate:



`MAJOR.MINOR.PATCH`



Example:



`v0.1.0`



The `0.x` versions represent active development before the first stable release.



Version `1.0.0` will represent the first mature research and software release.
